Frequently asked questions

What is MedBilling Fee Desk?

A fast reference for physicians and billing staff to look up physician fee codes, fees, modifiers, governing rules and diagnostic codes. For Alberta it uses the Schedule of Medical Benefits (SOMB) effective April 1, 2026 and the Alberta Health ICD-9 diagnostic code list.

Which provinces and territories are included?

Live: Alberta, Saskatchewan, Manitoba, Newfoundland and Labrador, Northwest Territories and Yukon. Nova Scotia (approval pending), British Columbia (approval pending), Ontario (approval pending), Quebec (approval pending), Prince Edward Island (approval pending) and New Brunswick (approval pending) show no fees or codes until their governments allow the schedule to be republished. Each jurisdiction's source, edition and licence is shown in the app's footer and on the Resources page; see also Terms: jurisdictions.

Does it work without internet?

Yes. The schedules are stored in the app, so search, code details, rules, favourites and recent codes work in airplane mode. Only links to outside websites need a connection.

Is it free? Do I need an account?

It is free, with no ads, no in-app purchases and no subscription. There is no account or sign-in.

Is my information private?

Yes. The native app collects no data (App Store label: Data Not Collected) and has no analytics or tracking. Your favourites and recent codes stay on your device. See the Privacy Policy.

How do I back up my favourites or move them to a new phone?

Open ★ Favourites and tap Export to save a file (for example to Files or email it to yourself). On the new device, tap Import and choose that file. The file includes your favourite groups and the links between fee codes and ICD-9 codes; importing merges them with what is already on the device (nothing is deleted, and a link that would give a code more than 3 links is skipped). A file from an older version has no groups or links, so its codes arrive under Ungrouped. An older version of Fee Desk can still import a newer file: every favourite arrives, without the parts that version doesn't know.

How do I group my favourites (by specialty, doctor or my own name)?

Open ★ Favourites and tap + New group. Choose the type: Specialty (pick from the list, such as Family Medicine or Obstetrics & Gynecology, or type your own), Doctor (type the doctor's name) or Custom (any name), then tick the favourites that belong in it. Each group is a folder with a count; tap its name to open or close it, and Fee Desk remembers which ones you closed. Favourites that aren't in a group are listed under Ungrouped, so nothing from before is lost.

When you tap ☆ on a code, a quick sheet lets you choose its group(s); the group you used last is ticked for you. A code can be in several groups. Tap ⋯ on a code to move it, copy it to another group or remove it from a group, and ⋯ on a group to add codes, rename it, move it up or down, or delete it (you choose whether its codes stay as favourites or are removed). Use Filter favourites to search, and choose Custom order or A–Z for the groups. In pick mode from MedBilling Logs, tapping a code inside a group sends it back as usual. Group names, including doctors' names, are your own labels and stay on your device.

How do I link a fee code to the ICD-9 codes I usually bill with it?

When you tap ☆ on a fee code, Fee Desk offers Link ICD-9 (you can ignore it). Pick up to 3 ICD-9 codes: your ICD-9 favourites and the suggested codes are listed first, or search by code or words. Tapping ☆ on an ICD-9 code works the other way: link it to up to 3 fee codes. Later, tap ✎ beside the linked codes, or ⋯ on the favourite, to add or remove links.

In ★ Favourites each fee code shows its linked ICD-9 codes side by side (code and a short description), and each ICD-9 favourite shows its fee codes. A link works both ways, so linking 03.04A to V22.1 shows on both. A code can have at most 3 links; Fee Desk tells you when one is full. Links are your own, stay on your device and are included in Export. In pick mode from MedBilling Logs, tapping a linked ICD-9 code sends that code to the Dx cell (one code per pick, as before).

How are ICD-9 codes suggested?

On a code's detail page the app lists up to 8 ICD-9 codes that commonly fit that service, each with a "Why suggested" line. The matching is built into the app (Alberta Health does not publish a code-to-diagnosis map), so treat suggestions as a starting point and choose the diagnosis that matches your documentation.

How do I send a code back to MedBilling Logs?

In MedBilling Logs, tap ↗ in a Fee code(s) or Dx (ICD-9) cell. Fee Desk opens in pick mode with a slim bar: "Picking a code for MedBilling Logs, tap a code to send it back · Cancel". Tap a billing code or an ICD-9 code and it goes straight into that cell in MedBilling Logs. Only the code travels (no patient information). Cancel returns without changes. Outside pick mode Fee Desk works as usual.

What if a fee or code looks wrong?

Treat the official government schedule as the source of truth. Email us at delaramedbilling@gmail.com with the code, province and what looks wrong so we can investigate. Using the app does not guarantee claim acceptance or payment.

I found an error or want a change. How do I tell you?

In the app, tap Suggest a change at the bottom of the screen. It opens your email app with a message to delaramedbilling@gmail.com. Or email us directly. Including the code, province and what looks wrong helps us fix it quickly.

When is the data updated?

When a province publishes a new schedule edition, we update the data and release a new version of the app. The edition date is shown in the app footer.
